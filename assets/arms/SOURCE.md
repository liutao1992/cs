# First-person arms

Game Ready FPS Arms by zahers, supplied by the user as arms.fbx and Textures.zip.
Source: https://www.cgtrader.com/free-3d-models/character/man/game-ready-fps-arms
Listed license: CGTrader Royalty Free (no AI), not CC0. Do not redistribute as a standalone asset pack.

prepare-arms.py exports only the skinned arms and skeleton, with color and normal maps.
embed-arms.mjs embeds the GLB for offline game loading. No source animations are supplied.
