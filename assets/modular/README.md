# Modular city assets

Kenney Modular Buildings, CC0. Original license included in LICENSE.txt.
Source: https://github.com/petroulacl/fps-buildings-env-kit at commit
`1dd8e932402deb82422920df2e7fd079391e55d3`, directory
`buildings/kenney-modular-buildings/Models/GLB format/`.
`modular.png` is the original `Textures/colormap.png`.

Selected house and tower models are used in the 都会广场 and 红砖庭院 maps.
Run `node scripts/prepare-suburban.mjs modular` then `npm run build` to
regenerate the baked geometry and offline HTML. Original GLBs are retained.
