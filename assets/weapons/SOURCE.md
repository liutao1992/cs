# Weapon sources

AWP and Glock-style PEW: Styloo Guns Asset Pack GLTF FBX V1.1, CC0.
https://styloo.itch.io/guns-asset-pack

M4A1 and USP: Maia Studios Firearms Kit Free.
https://maiastudios.itch.io/firearms-kit-free
Author explicitly permits modification, distribution, and commercial use.
Converted from the original .blend files using scripts/convert-weapons.py.
Original archives are retained as M4A1-source.zip and USP-source.zip.
To rebuild: run Blender in background mode with scripts/convert-weapons.py,
then `node scripts/prepare-weapons.mjs` and `npm run build`.

Downloaded 2026-09-10. The game keeps its original weapon names and stats;
the PEW model is used as the visual representation of the Glock slot.
