# DUST SECTOR · 沙域行动

一款本地浏览器第一人称战术射击游戏，使用 Three.js 构建。全部代码、样式和依赖已打包进 `index.html`，无需联网。环境材质采用 CC0 照片纹理（Poly Haven / ambientCG，见 `assets/textures/SOURCE.md`)，枪械与音效在本地生成。

## 启动

**直接双击 `index.html` 即可游玩。** 无需安装 Node.js、无需运行命令、无需启动服务器，也不需要联网。可以将这个 HTML 单独复制到其他文件夹或电脑上使用。

推荐使用桌面版 Chrome 或 Edge，开启浏览器图形加速，使用键盘和鼠标。打开后点击「进入战场」，按 Esc 暂停并释放鼠标。如果默认打开方式是编辑器，请右键文件，选择「打开方式 → Google Chrome」。

## 修改源码与重新打包

开发时需要 Node.js 22 或更新版本：

```sh
npm install
npm run build
npm start
```

`npm run build` 从 `src/index.template.html`、`src/*.js` 和 `style.css` 重新生成独立的 `index.html`，修改源码后需要重新构建。请勿直接编辑生成文件。环境纹理由 `node scripts/prepare-textures.mjs` 从 `assets/textures/` 编码进 `src/textures-asset.js`，日常改图无需重复执行。

服务器方式仍可选用：`npm start` 后打开 **http://localhost:3000**，或在 macOS 双击 `启动游戏.command`。服务器仅监听本机 `127.0.0.1`；修改端口可使用 `PORT=3001 npm start`。

| 操作 | 按键 |
| --- | --- |
| 移动 / 观察 | WASD / 鼠标 |
| 开火 / 瞄准 | 鼠标左键 / 按住右键 |
| 静步 / 蹲下 / 跳跃 | Shift / C / 空格 |
| 换弹 / 切枪 | R / 1-5 直接切枪、Q 循环 |
| 投掷物 | X 选择、G 投掷（竞技模式按 B 购买） |
| 近战 | V（背刺直接击杀） |

| 战绩 / 暂停 | 按住 Tab / Esc |

## 玩法

- **清剿行动**：150 秒内消灭所有机器人。新兵、标准、精英分别为 3、5、7 名敌人，反应、命中率和移动速度不同。
- **爆破行动**：在 A / B 点安放炸弹并守卫 35 秒。敌人在目标附近连续拆除 7 秒则失败。炸弹安放前消灭所有敌人也会获胜。
- **竞技对抗**：12 局经济模式，半场换边。购买菜单包含步枪、狙击枪、护甲、拆弹器与手雷 / 闪光 / 烟雾。
- **生存防线**：无尽波次，每 3 波出现 Boss「泰坦」；每波之间从三张强化卡中选一张（伤害、射速、换弹、护甲、吸血等，可叠加）。
- **击杀反馈**：命中血雾、弹壳、镜头震动、死亡倒地、受击方向指示与低血量心跳；连杀播报与慢动作。
- **投掷物与油桶**：高爆手雷半径伤害、闪光弹致盲（玩家与敌人）、烟雾遮挡敌我视线；红色油桶可被打爆并连锁引爆。
- **敌人 AI**：步枪手 / 冲锋手 / 狙击手三种兵种，会拉枪、残血找掩体后撤、被击杀后同伴警觉，竞技模式有包点执行与防守分工。
- **局外成长**：武器专精（击杀累积等级）、每日行动（按日期生成、奖励信用点）、信用点解锁与装备枪械涂装。
- **战场规则**：部署时可选沙尘暴、精锐敌军、弹药紧张、高频补给或随机词条，得分按倍率结算。
- 包含掩体碰撞、机器人绕障寻路与视线检查、爆头伤害、护甲、枪械后坐力、移动散布、弹匣和备用弹药、合成音效、小地图、击杀记录及多回合比分。
- 暂停时可调整灵敏度、音量和阴影质量，设置保存在当前浏览器。切换窗口会自动暂停。

这是受经典 CS 沙漠地图氛围启发的原创单人游戏，不包含 Valve 官方地图、模型或音频。当前为轻量级三维场景，未实现 CS2 级写实资产、多人联机与队友系统。

## 验证

```sh
npm test
npm run build
npx playwright test
```

逻辑测试覆盖墙体防穿透、边界、寻路、护甲、弹药守恒、投掷物伤害 / 致盲、AI 兵种目标选择、强化叠层、专精与每日行动、战场规则；浏览器测试覆盖真实鼠标锁定与键盘操作、射击、换弹、开镜、投掷物、近战、爆炸油桶、暂停恢复、爆头、碰撞、爆破与回合结算、生存选卡、连杀奖励、军械库持久化，以及窄屏部署界面和本地资源请求。浏览器测试默认使用 macOS Chrome，其他安装位置可通过 `CHROME_PATH` 指定。

浏览器测试也会把 `index.html` 单独复制到临时文件夹，在断网模式下通过 `file://` 打开并验证鼠标锁定、移动射击、换弹与暂停，确保无需其他项目文件。

URL 添加 `?test` 仅用于本地自动化，提供 `window.__game` 状态检查与测试控制；普通入口不提供这些测试接口。截图保存在 `artifacts/`。
